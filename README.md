# Natural Language Processing (NLP) — Lab Repository

Welcome to my **Natural Language Processing (NLP) Lab Repository**.  
This repository contains all the laboratory exercises, assignments, practical implementations, and related work completed as part of my academic coursework.

## 📚 About the Repository

The purpose of this repository is to maintain and organize all the **NLP laboratory work** completed during the semester.

The labs cover fundamental concepts of Natural Language Processing, including text preprocessing, tokenization, feature extraction, word embeddings, language models, and other NLP techniques.

## 🧠 Topics Covered

The repository may include practical implementations related to:

- Text Preprocessing
- Tokenization
- Stopword Removal
- Stemming and Lemmatization
- Part-of-Speech (POS) Tagging
- Named Entity Recognition (NER)
- Bag of Words
- TF-IDF
- Word Embeddings
- Word2Vec
- GloVe
- FastText
- N-gram Language Models
- Sentiment Analysis
- Text Classification
- Sequence Processing
- Attention Mechanism
- Transformer-based NLP
- BERT and other Language Models
- Other NLP concepts covered during the course
